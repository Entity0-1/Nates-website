FLAGSHIP PROJECT · GAME & SIMULATION ENGINEERING

Escape Circuit / Fly Brain

Built a fully 3D first-person game in which compact controllers derived from measured fruit-fly connectivity influence escape actions and spontaneous turns. The project brings together real-time gameplay, neural-data processing, simulation architecture, testing, scientific documentation, and release engineering.

  • Complete gameplay system: implemented first-person movement, mouse tracking, charge-and-release swatter mechanics, timed rounds, scoring, pause/restart states, audio, telemetry, and a twelve-second split-screen replay.
  • Connectome data pipeline: built a reproducible Python workflow that verifies checksums, scans MaleCNS v1.0 source data, and generates compact, reviewable escape and flight-turn artifacts.
  • Real-time controller architecture: designed in-process neural providers plus an optional non-blocking Python reference service, keeping gameplay responsive even when external computation is unavailable or late.
  • Simulation engineering: translated modeled visual looming into distinct takeoff, directional escape, airborne-saccade, steering, power, and landing signals that drive the fly’s 3D state machine.
  • World & collision systems: adapted a detailed apartment into a navigable game space with shared furniture footprints, room-to-room waypoints, structural collision, movement substeps, and swept checks for fast-moving objects.
  • Quality & delivery: added deterministic Godot and Python tests, linting, type checks, data provenance, third-party attribution, and automated Windows and Web release packaging.

Engineering result: a self-contained game that runs without a server, account, or internet connection, while retaining an independently implemented Python path for verification and inspection.

Measured connectivity informs selected controllers; stimulus encoding, neural dynamics, action decoding, and biomechanics are explicitly documented engineering models—not a whole-brain simulation.

PYTHON APPLICATION · INFORMATION RETRIEVAL

RAG Pipeline

Built Grounded Search, the retrieval engine for my RAG Pipeline, to make local document collections searchable. Implemented the full path from PDF, DOCX, Markdown, and text ingestion to ranked passages with source citations.

  • Search implementation: built overlapping chunks, an inverted index, and configurable TF-IDF / BM25 scoring with reproducible ranking.
  • Feature delivery: implemented document uploads, index building and inspection, and search through a CLI and local HTTP interface.
  • Data integrity: added schema validation and atomic index replacement; validated uploads before replacing files and rejected unsafe filenames.
  • Automated verification: wrote tests for upload-to-search flows, overwrite handling, corrupt indexes, and CLI errors, with GitHub Actions configured for Windows/Linux and Python 3.11/3.14.
  • Developer handoff: packaged the application with its web assets and documented installation, usage, ranking algorithms, and example workflows.

Result: a local application that lets users upload documents, build a searchable index, and inspect original evidence through either interface.

03 PYTHON TOOLING · DATA EXTRACTION

iPhone Backup Extractor

Developed a Python utility that reads an iPhone backup’s SQLite manifest, resolves its internal file mapping, and exports Voice Memo recordings and the Notes database into organized folders.

  • Data access: queried the SQLite manifest to map original paths to the opaque identifiers used to store backup files.
  • Compatibility: resolved files in hashed subfolders and added a fallback for older flat backup layouts.
  • Export workflow: organized recordings and Notes database files into separate folders while preserving file metadata.
  • Error handling: checked for a missing manifest, skipped unavailable files, and reported extracted files and the final export count.

Result: automated manifest lookup and file export, turning opaque backup storage into organized audio and database files. Delivered with configuration and usage instructions using Python’s standard library.
